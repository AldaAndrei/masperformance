Export Database to SQL

Această secțiune vă permite să generați și să descărcați o copie completă de siguranță a bazei de date a site-ului Mas Performance în format SQL. Fișierul generat conține structurile tabelelor (CREATE TABLE) și toate înregistrările curente stocate local (INSERT INTO) pentru setările site-ului, proiectele active, testimoniale și formularele de contact depuse.

-- Exemplu structură export SQL: CREATE TABLE `site_settings` ( `key` varchar(100) NOT NULL, `value` text, PRIMARY KEY (`key`) ); CREATE TABLE `projects` ( `id` bigint(20) NOT NULL, `title` varchar(255) DEFAULT NULL, `desc_ro` text, `desc_en` text, `stock` varchar(100) DEFAULT NULL, `tuned` varchar(100) DEFAULT NULL, `image` text, PRIMARY KEY (`id`) );
